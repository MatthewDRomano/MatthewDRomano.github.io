  • Pipelined MIPS CPU

    Verilog on a Xilinx Zynq FPGA

    A 5-stage pipelined MIPS processor that runs 30+ instructions. It handles data hazards with forwarding and load-use stalls, and it resolves branches in the EXE stage. It started as a class project and I kept building on it over the summer.

  • AtomiC-IO

    C networking library

    A TCP client-server library with broadcast messaging and its own dependency-free test suite. I load-tested it with 128 concurrent clients across multiple machines at flood rate, and it dropped zero messages.

    Code on GitHub

  • dirsyncd

    C daemon on Linux inotify

    A daemon that keeps directories in sync by watching them with inotify. It keeps up with thousands of directory updates and deletions per second without missing any.
