Most of my work is low-level, written in C and Verilog, with some hardware on the side. Most of the code is on GitHub.

All my repos on GitHub

  • AtomiC-IO

    C networking library

    A C library for TCP messaging, including broadcasting to every connected client. Each client gets its own thread that polls for I/O, and the shared state and async logging are mostly lock-free, built on C11 atomics. Under load from 128 clients across multiple machines at flood rate, it dropped zero messages.

    Code on GitHub

  • Pipelined MIPS CPU

    Verilog on a Zynq-7000 FPGA

    A 5-stage pipelined MIPS processor that runs 30+ instructions. It handles data hazards with forwarding and load-use stalls, and it resolves branches in the EXE stage. It started as a class project and I kept building on it over the summer.

    Code on GitHub

  • dirsyncd

    C daemon on Linux inotify

    A daemon that mirrors file changes between directories as they happen, using inotify events instead of rescanning the tree. I stress-tested it at thousands of directory creates and deletes per second with no missed changes.

    Code on GitHub

  • PCB business card

    KiCad hardware design

    The card that brought you here. It's a two-layer board where a CH32V003 drives an OLED, and an NFC tag with a copper loop antenna sends phones to this site.

  • nRF52840 sensor firmware

    Bare-metal C, in progress

    Firmware for a Nordic nRF52840 that reads motion data from an LSM6DSO sensor over SPI, written without vendor libraries. I'm setting up the SPI peripheral straight from the register-level datasheet.
